# Changelog

All notable changes to the `executor-node` (relayer service) will be documented in this file.

## [Unreleased] - 2026-07-07

### Added
- **Acoustic Realism checks (Layer B1)**: Added validation rules checking client-reported spectral flatness. Rejects digital silence or loopback injections if flatness is extremely flat (`> 0.85`) or tone-degenerate (`< 0.015`).
- **Parent-Wallet Sybil defense (Layer D1)**: Implemented on-chain parent-wallet tracking by decoding the wallet's creation/funding transaction. If the parent wallet completed an identity registration within the last 24 hours, the child wallet's reputation risk is penalized by `+0.5` up to `1.0`.
- **Graduated Friction CAPTCHA (Layer C)**: Suspicious Composite Risk Scores (`0.45 - 0.75`) on first attempts now return a `captcha_required` soft-reject. This prompts the client to complete a dynamic voice/motion challenge using a fresh phrase generated by the relayer.
- Added comprehensive unit tests for attempts tracking, client signal deserialization, and mock reputation states.

## [0.1.1] - 2026-07-06

### Added
- **Observe-Only Telemetry**: Added logging logic for optional client-side automation signals (tells) and wallet reputation markers without affecting the validation pass/fail decision.
- Accept and parse `virtual_device` capture signals from updated client SDKs.

## [0.1.0] - 2026-05-15

### Added
- **Per-IP Rate Limiting (Layer C)**: Added token-bucket middleware limiting verify endpoints to `30` requests per minute.
- **IP Address Anonymization**: Implemented network-level IP masking in logs (IPv4 host octet zeroed to `/24`, IPv6 to `/48`) to prevent PII leakage.
- **Prometheus Metrics**: Exposed `entros_per_ip_rate_limit_rejected_total` at the `/metrics` endpoint.
- **Constant-Time Verification**: Enforced constant-time byte comparisons for validation API key authentication to mitigate timing side-channel attacks.
- Moved sliding-window attempt cache cleanup to an asynchronous background worker loop.
- **SAS Attestation**: Integrated Solana Attestation Service (SAS) client, added one-time setup scripts for devnet schema/credential creation, and wired `/attest` endpoint.
- **Status & Metrics**: Added `/status` endpoint with uptime reporting and a 30s TTL-cached relayer balance read.
